
## 🎬 Movie Ticket Booking System

A C++ console application that simulates a complete movie ticket booking experience. Users can register, log in, browse movies by genre, view movie details, select theatres and show timings, choose seats, order snacks and beverages, and complete payment—all through an interactive text-based interface.

---

### ✨ Features

✅ User Registration and Login system <br>
✅ Browse movies by genres (Romance, Comedy, Drama, Horror, Thriller) <br>
✅ Display detailed information about movies (cast, ratings, description) <br>
✅ Selection of theatres and show timings <br>
✅ Interactive seat booking with live seat maps <br>
✅ Add snacks and beverages to the order <br>
✅ Calculate total payment amount <br>
✅ Secure payment simulation <br>
✅ Console-based, user-friendly UI

---

### 🛠️ Technologies Used

* **Language:** C++
* **Concepts:** File I/O, functions, arrays, string manipulation, console I/O, control structures

---

### 🚀 How to Run

1. Make sure you have a C++ compiler installed (e.g. g++, MinGW, etc.)
2. Clone this repository or copy the `.cpp` file into your environment.
3. Compile the code:

   ```bash
   g++ Movie\ Ticket\ Booking\ System_Tanisha\ Shaha.cpp -o MovieTicketBooking
   ```
4. Run the executable:

   ```bash
   ./MovieTicketBooking
   ```

   or on Windows:

   ```cmd
   MovieTicketBooking.exe
   ```
